# Homebrew tap for DuckFleet

Install the native DuckFleet CLI on macOS arm64, Linux x86_64, or Linux aarch64:

```sh
brew install athvin/duckfleet/duckfleet
duckfleet version
```

See the [DuckFleet CLI guide](https://github.com/athvin/duck-fleet/blob/main/docs/cli.md) for project initialization and configuration.
